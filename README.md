# Afghan Carpets

A modern luxury Afghan & Persian carpet e-commerce website built with Next.js 15, TypeScript, Tailwind CSS, and immersive UI/UX animations.

This project showcases handcrafted carpets with elegant layouts, multilingual support, responsive design, animated sections, and premium shopping experiences inspired by modern luxury brands.

---

## ✨ Features

- Modern luxury UI/UX
- Fully responsive design
- Multilingual support
  - English
  - فارسی (Farsi)
  - پښتو (Pashto)
- Product collections & categories
- Interactive search overlay
- Shopping cart system
- Wishlist interactions
- Smooth animations & transitions
- 3D hover card effects
- Mobile-first design
- Optimized image handling using Next.js Image
- SEO-friendly architecture
- Clean component structure

---
